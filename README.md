# BugHunter

Revisão de código por IA que roda dentro da sua empresa: encontra e conserta defeitos de concorrência, transação e mensageria em sistemas Java, sem que o código-fonte saia da sua rede.

Site: https://heitordfb.github.io/bughunter/

Os números do site vêm de um laboratório que usa somente dados fictícios.
